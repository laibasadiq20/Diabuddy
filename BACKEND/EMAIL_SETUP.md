# Gmail setup for real signup and OTP emails

To make DiaBuddy send registration and login OTP emails to a real inbox, configure Gmail SMTP in the backend environment file.

## 1) Create a Gmail app password
1. Sign in to your Google account.
2. Enable 2-Step Verification.
3. Go to Google Account > Security > App passwords.
4. Create a new app password for "Mail".
5. Copy the 16-character password.

## 2) Update the backend environment file
Open [BACKEND/.env](BACKEND/.env) and replace the placeholder values:

```env
EMAIL_USER=your_gmail_address@gmail.com
EMAIL_PASS=your_gmail_app_password
EMAIL_FROM="DiaBuddy Support <your_gmail_address@gmail.com>"
```

Use your real Gmail address and the app password you just created.

## 3) Restart the backend
From the backend folder, restart the server:

```bash
npm start
```

## 4) Test it
You can verify the mail setup by running:

```bash
node test-email.js your_email@example.com
```

If the credentials are correct, the email will be sent to that inbox.

## Important
- Do not use your normal Gmail password here.
- Use the app password generated by Google.
- If the credentials are wrong, the server will show a clear SMTP error.
